## Trust Boundaries

| Boundary                       | Description                                                                                                                                                               |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| FGS lifecycle / JobScheduler   | the FGS + the UIDT JobService run with the app's privileges — no external input                                                                                           |
| OEM deep-link intents          | `startActivity` to an explicit `ComponentName` — could `ActivityNotFoundException`-crash if unguarded; could (theoretically) be intercepted if it were an implicit action |
| AOSP battery-opt prompt        | the system handles `ACTION_REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` — Play-policy-sensitive but moot at MVP (apkRollout flavor isn't on Play)                                |
| `UploadJobService` `<service>` | declared `exported="false"` + `BIND_JOB_SERVICE` — only `JobScheduler` can bind it                                                                                        |
