---

## Sampling Rate

- **After every task commit:** Run the quick run command for the touched workspace (backend / mobile JS / Android).
- **After every plan wave:** Run the full suite command for every workspace any wave plan touched (and the APK assemble for any Android-touching wave).
- **Before `/gsd-verify-work`:** Full suite must be green in all touched workspaces; the Android APK must assemble.
- **Max feedback latency:** ~180 s (the slowest quick-run path is the Android `--tests '<Class>'` target).
