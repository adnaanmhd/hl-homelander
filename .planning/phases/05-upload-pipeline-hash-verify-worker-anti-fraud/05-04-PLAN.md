## Trust Boundaries

| Boundary                      | Description                                                                                                                                                                            |
| ----------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| device FS → app (queue store) | `UploadQueueStore` reads/writes `filesDir/upload-queue/queue.json` under the app's private storage — no untrusted input; the row data is what the app itself wrote at `enqueue()` time |
| RN bridge (JS ↔ native)      | JS calls `enqueue/pause/resume/getQueue/clearVerified`; the args (`recordingId`, paths, `ownerUserId`) originate from the app's own capture flow + auth store, not from a server       |
| shared phone, multi-account   | the queue store is per-app, not per-account — cross-account leakage is the threat                                                                                                      |

## STRIDE Threat Register

| Threat ID | Category                          | Component                                                                         | Disposition | Mitigation Plan                                                                                                                                                                                                                                                                                     |
| --------- | --------------------------------- | --------------------------------------------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-5-04-01 | Elevation of privilege / Spoofing | cross-account upload-queue drain on a shared phone (User B drains User A's queue) | mitigate    | Every queue row carries `ownerUserId` (= the signed-in `sub` when the recording was made); `bootstrap(currentSub)` only returns/resumes rows where `ownerUserId == currentSub`; the JS UI only renders own-rows; logout preserves rows but does not drain them (Plan 05-08 wires the logout-abort). |
| T-5-04-02 | Tampering                         | queue.json corrupted (interrupted write, FS error)                                | mitigate    | Atomic write (`.partial`-then-rename, mirroring `MetadataComposer.writeAtomic`); `read()` tolerates a corrupt/missing file by returning an empty list + logging — never crashes.                                                                                                                    |
| T-5-04-03 | Information disclosure            | the queue store holding secrets                                                   | accept      | The queue holds `recordingId`s, file paths, part-ETags, an `ownerUserId` (a ULID) — no tokens (those stay in Keychain), no PII beyond the timestamped filename. Documented. Not encrypted (it's app-private storage).                                                                               |
| T-5-04-04 | Tampering                         | a practice recording leaking into the upload queue / to S3                        | mitigate    | `enqueue()` refuses any row whose `taskId == "__practice__"` OR whose `mp4Path` is under `files/practice/` (D-08) — practice recordings never enter the queue, never reach `/recordings/init` (the `__practice__` taskId would also fail the server-side `recordings.taskId` FK).                   |
| T-5-04-05 | (theoretical) intent hijack       | the `<service android:name=".upload.UploadJobService">` exported                  | mitigate    | `android:exported="false"` + `android:permission="android.permission.BIND_JOB_SERVICE"` — only `JobScheduler` can bind it.                                                                                                                                                                          |
