## Trust Boundaries

| Boundary                     | Description                                                                                                                                                                                  |
| ---------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| device FS → app (boot sweep) | `CaptureLaunchSweep` reads/deletes files under the app's private `filesDir` — no untrusted input crosses; paths are derived from the recordings dir listing, never from a network/IPC source |
| RN navigation reset          | `handleStop` resets the navigator to MainTabs — local state only, no external input                                                                                                          |

## STRIDE Threat Register

| Threat ID | Category               | Component                        | Disposition | Mitigation Plan                                                                                                                                                                       |
| --------- | ---------------------- | -------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| T-5-01-01 | Tampering              | `CaptureLaunchSweep` delete path | mitigate    | Delete targets are computed from `recordingsDir.listFiles()` base names under the app's private storage only — never from a server- or IPC-supplied path; no path traversal possible. |
| T-5-01-02 | Denial of Service      | boot sweep                       | accept      | A malformed/huge orphan fragment is now deleted, not re-finalized — strictly less work than before. No DoS surface.                                                                   |
| T-5-01-03 | Information disclosure | recovery toast                   | accept      | The toast string is a fixed constant ("Recording recovered after force-quit — uploading.") — no recording id / filename / PII in it.                                                  |
