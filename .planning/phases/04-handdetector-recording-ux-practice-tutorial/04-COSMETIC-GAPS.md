## Cosmetic / metadata items

- **`start_gate.duration_ms` is occasionally bogus.** A gate-PASS practice run stamped `start_gate.duration_ms: 59929` (≈ the whole 60 s recording) in the metadata JSON, while Skip runs stamp sane values (~600–2700 ms). Looks like `state.gate.startedAt` isn't reliably captured before `state.gate.confirmedAt` on the pass path (`gateDurationMs = confirmedAt − startedAt` in `RecordingScreen.tsx`'s `run()`). Harmless to the recording itself; the metadata field is just wrong sometimes.
- **`ViewManagerPropertyUpdater: Could not find generated setter for class HumynGateCameraViewManager`** — a benign-looking logcat warning every time `<HumynGateCameraView>` mounts. The native ViewManager (`gatecamera/HumynGateCameraViewManager.kt`) doesn't declare a generated prop setter for the prop(s) RN passes (`style`?). Hasn't visibly broken the preview; tidy up the ViewManager's `@ReactProp` declarations.
- **Rotate-prompt phone glyph** — eyeball it. The glyph is the prototype's portrait-phone SVG tilting CCW to landscape (`RotatePrompt.tsx`); a screenshot caught it mid-tip looking like a landscape rectangle. Confirm the animation reads as a clear "rotate your phone" gesture on-device (it animated; just sanity-check it isn't confusing).
- **`onSessionStart` / `onSessionStop` aren't `adb logcat` lines.** The `04-MANUAL-SMOKE.md` §3 expectation "`adb logcat | grep -i onSessionStart\|onSessionStop\|HumynCaptureModule` shows the events" is off — these are RN-bridge events (the upload-pause seam, log-only at Phase 4), not native logcat lines. RecordingScreen subscribes to `onSegmentStart` / `onSegmentComplete` (updates `segMetaRef`). Adjust the runbook wording, or add a native `Log.i` at the session-start/stop seam if a logcat trace is wanted.
- **No `is_practice` field in the recording metadata JSON.** The `04-MANUAL-SMOKE.md` §2 expectation "confirm the metadata carries `is_practice: true`" is stale — practice recordings are segregated by the `files/practice/` directory + `task_id: __practice__` (the `.session.json` sidecar _does_ carry `is_practice`, but the finalized `{base}.json` doesn't). Either add `is_practice` to the finalized metadata (belt-and-suspenders for Phase 5's upload filter) or update the runbook assertion.
- **PracticeIntro copy deviation** — already shipped (commit `eaaa1fe`): body shortened to "We'll walk you through one short recording — 60 secs, to get the feel"; the "This is a practice task — it does not count towards your contribution." muted line removed (owner directive). Reflect this back into `design-spec.md §6` / `04-UI-SPEC.md § Copywriting` in a doc pass. (Same as the en-US-cue-voice and RigTutorial-framing-tip owner deviations — flagged in the relevant file headers + `CLAUDE.md`.)
- **`04-MANUAL-SMOKE.md` §2 text is stale on a few details** (the gate-pass description still says "80 ms vibrate" → it's 120 ms; "en-IN female TTS" → it's en-US female; "5 × 400 ms" gate dwell → it's 2 × 250 ms; no mention of the live camera preview from `'ready'` onward).
