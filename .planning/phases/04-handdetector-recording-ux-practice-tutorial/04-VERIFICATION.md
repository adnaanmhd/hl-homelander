The other actionable gaps (**WR-01**/HAND-11, **WR-02**, **WR-07**, **WR-03**, **WR-04**, plus the WR-06/IN-01/IN-02/IN-09 sweep) are all closed in code — confirmed by direct inspection (see the tables below). **Why the status is `human_needed`, not `passed`:** the phase goal is not "the recording-surface code exists and is wired" — it is "a user can … capture a _real recording_ … with the full _thermal/battery/TTS lifecycle handling_ … and complete the _60-second practice-recording onboarding flow_".
