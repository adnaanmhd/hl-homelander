<objective>
Set up the Android product-flavor infrastructure for **two** flavors: `apkRollout` and `playStore`. Different `applicationId`s allow co-installation; per-flavor `AndroidManifest.xml` source sets gate the `REQUEST_INSTALL_PACKAGES` permission so the Play Store APK never declares it (auto-rejection by Play Console policy if it did). Includes a CI manifest-merger gate, a typed JS wrapper for runtime flavor reads, and per-flavor `.env` files.

**The plan does NOT build a third `compatRecon` flavor.** DIST-07 is rescinded per CONTEXT.md D-DIST-01; the requirements field carries the DIST-07 marker so the coverage gate sees the ID, but no code is built for it.

Purpose: DIST-01..03 + AUTH-06 are the wire-side enforcement of the apkRollout vs playStore distinction. Getting the manifest-merger right is binary — either it works (apkRollout has the permission, playStore doesn't), or the Play Store listing fails the automated policy review on submission. The CI gate prevents future regressions.

Output: Android Gradle config with two productFlavors, distinct applicationIds, signing configs reading from CI env vars, runtime flavor exposure via a custom Kotlin TurboModule, manifest-merger verification script, per-flavor `.env` files, and the typed JS wrapper.
</objective>

```kotlin
import com.facebook.react.bridge.ReactApplicationContext
import com.facebook.react.bridge.ReactContextBaseJavaModule
import com.facebook.react.bridge.ReactMethod
import com.facebook.react.bridge.Promise
import com.facebook.react.module.annotations.ReactModule
import ai.humynlabs.capture.BuildConfig

@ReactModule(name = AppFlavorModule.NAME)
class AppFlavorModule(reactContext: ReactApplicationContext) : ReactContextBaseJavaModule(reactContext) {
companion object { const val NAME = "AppFlavor" }
override fun getName() = NAME

    // Sync constants — NativeModules.AppFlavor.flavor and .applicationId are
    // available without a Promise round-trip.
    override fun getConstants(): MutableMap<String, Any> {
        return hashMapOf(
            "flavor" to BuildConfig.FLAVOR_NAME,
            "applicationId" to BuildConfig.APPLICATION_ID,
        )
    }

    @ReactMethod
    fun get(promise: Promise) {
        promise.resolve(hashMapOf(
            "flavor" to BuildConfig.FLAVOR_NAME,
            "applicationId" to BuildConfig.APPLICATION_ID,
        ))
    }

}
````

`apps/mobile/scripts/verify-merged-manifests.sh` (executable, used by CI):
```bash
#!/usr/bin/env bash
set -euo pipefail

# Verifies that:

# apkRollout merged manifest CONTAINS REQUEST_INSTALL_PACKAGES

# playStore merged manifest does NOT contain REQUEST_INSTALL_PACKAGES

# This is the canonical guard against accidentally leaking

# REQUEST_INSTALL_PACKAGES into the Play Store APK.

ROOT="$(cd "$(dirname "$0")/.." && pwd)"
ANDROID_DIR="$ROOT/android"
cd "$ANDROID_DIR"

echo "[verify-manifests] Building merged manifests for both flavors ..."
./gradlew :app:processApkRolloutDebugManifest :app:processPlayStoreDebugManifest

# AGP places the merged manifest at one of these paths depending on version.

# Try both; pick whichever exists.

candidate_paths=(
"app/build/intermediates/merged_manifest/${1}/AndroidManifest.xml"
  "app/build/intermediates/merged_manifests/${1}/processManifest/AndroidManifest.xml"
"app/build/intermediates/merged_manifests/${1}/AndroidManifest.xml"
  "app/build/intermediates/manifest_merge_blame_file/${1}/manifest-merger-blame-${1//Debug/-debug}-report.txt"
)

find_merged() {
local flavor_build="$1"
  for path_template in \
    "app/build/intermediates/merged_manifest/${flavor_build}/AndroidManifest.xml" \
 "app/build/intermediates/merged_manifests/${flavor_build}/processManifest/AndroidManifest.xml" \
    "app/build/intermediates/merged_manifests/${flavor_build}/AndroidManifest.xml"; do
if [[-f "$path_template"]]; then
echo "$path_template"
      return 0
    fi
  done
  echo "[verify-manifests] ERROR: cannot locate merged manifest for ${flavor_build}" >&2
  echo "[verify-manifests] candidates:" >&2
  printf '  %s\n' "${candidate_paths[@]}" >&2
exit 1
}

apk_manifest=$(find_merged apkRolloutDebug)
ps_manifest=$(find_merged playStoreDebug)

echo "[verify-manifests] apkRollout merged: $apk_manifest"
echo "[verify-manifests] playStore merged: $ps_manifest"

apk_count=$(grep -c "REQUEST_INSTALL_PACKAGES" "$apk_manifest" || true)
ps_count=$(grep -c "REQUEST_INSTALL_PACKAGES" "$ps_manifest" || true)

echo "[verify-manifests] apkRollout REQUEST_INSTALL_PACKAGES count: $apk_count (expected: ≥1)"
echo "[verify-manifests] playStore REQUEST_INSTALL_PACKAGES count: $ps_count (expected: 0)"

if (( apk_count < 1 )); then
echo "[verify-manifests] FAIL: apkRollout merged manifest must declare REQUEST_INSTALL_PACKAGES" >&2
exit 1
fi
if (( ps_count != 0 )); then
echo "[verify-manifests] FAIL: playStore merged manifest leaked REQUEST_INSTALL_PACKAGES — Play Store will reject this APK" >&2
exit 1
fi
echo "[verify-manifests] PASS"
````
