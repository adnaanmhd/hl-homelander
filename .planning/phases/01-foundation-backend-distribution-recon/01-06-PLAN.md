<objective>
Implement the entire `/tasks` surface: list (paginated), get-by-id, hybrid RRF search, and POST `/task-requests` for user-submitted task ideas. Deliver the seed pipeline that populates the 65-task taxonomy with embeddings at deploy time. This is the search subsystem that the mobile client will hit on every "browse tasks" screen in Phase 2+.

Purpose: API-06 collapses to one functional capability — discoverable tasks. The hybrid RRF query is the centerpiece; getting the SQL right (and parameterizing it correctly so user input cannot inject) is the entire reason this plan exists. The embedding pipeline is interesting only because seed time and query time MUST use the exact same model — divergence here means the HNSW index is querying at different vector geometry than it was indexed at, and recall collapses silently.

Output: 4 routes registered (`GET /tasks`, `GET /tasks/:id`, `GET /tasks/search`, `POST /task-requests`); a seed pipeline that runs idempotently via `pnpm seed:tasks`; vitest integration tests that seed a small fixture set and verify the RRF returns relevant results for "make tea" and "fold laundry" queries; embedding model loaded once at process start (cold-start cost ~1-3s per D-EMB-02).
</objective>

```typescript
// @xenova/transformers — Hugging Face JS port. CPU-only ONNX inference.
// Cold-start: first call loads ~24 MB model + tokenizer (~1-3s on Fargate t4g.medium per D-EMB-02).
// Subsequent embeds: ~50-200ms per query.

import { pipeline, type Pipeline } from '@xenova/transformers';

const MODEL_ID = 'Xenova/all-MiniLM-L6-v2' as const;
const EMBED_DIMS = 384 as const;

let _embedder: Pipeline | undefined;
let _loadPromise: Promise<Pipeline> | undefined;

async function getEmbedder(): Promise<Pipeline> {
  if (_embedder) return _embedder;
  if (!_loadPromise) {
    _loadPromise = pipeline('feature-extraction', MODEL_ID).then((p) => {
      _embedder = p;
      return p;
    });
  }
  return _loadPromise;
}

// Returns 384 floats (mean-pooled, normalized) — exact same configuration used at seed time.
// Critical: pooling='mean' and normalize=true are the bindings the model trains under.
// Changing either at query time (vs. seed time) breaks recall silently.
export async function embed(text: string): Promise<number[]> {
  const embedder = await getEmbedder();
  const output = await embedder(text, { pooling: 'mean', normalize: true });
  const arr = Array.from(output.data as Float32Array);
  if (arr.length !== EMBED_DIMS) {
    throw new Error(`embedder_returned_wrong_dims: expected ${EMBED_DIMS}, got ${arr.length}`);
  }
  return arr;
}

// D-EMB-04: embedded text shape — used by both seed (per task) and search query.
export function buildEmbeddedText(opts: { name: string; description: string; category: string }): string {
  return `${opts.name}. ${opts.description}. Category: ${opts.category}.`;
}

// Pre-warm — call this from /readyz or at boot if cold-start latency matters.
// At MVP we accept cold-start on first /tasks/search call.
export async function preloadEmbedder(): Promise<void> {
  await getEmbedder();
}
```

```typescript
import type { FastifyInstance } from 'fastify';
import type { ZodTypeProvider } from 'fastify-type-provider-zod';
import { and, asc, eq, gt, type SQL } from 'drizzle-orm';
import { db, schema } from '../../db/index.js';
import { TasksListQuerySchema, TasksListResponseSchema } from '@humyn/shared-types';

// Per-IP anonymous tier rate limit applies pre-auth (plan 04).
export default async function tasksListRoute(app: FastifyInstance) {
  app.withTypeProvider<ZodTypeProvider>().get('/tasks', {
    schema: { querystring: TasksListQuerySchema, response: { 200: TasksListResponseSchema } },
  }, async (req) => {
    const { cursor, limit, category, setting } = req.query;
    const filters: SQL[] = [];
    if (cursor) filters.push(gt(schema.tasks.id, cursor));
    if (category) filters.push(eq(schema.tasks.category, category));
    if (setting) filters.push(eq(schema.tasks.setting, setting));
    const rows = await db.select({
      id: schema.tasks.id,
      slug: schema.tasks.slug,
      name: schema.tasks.name,
      description: schema.tasks.description,
      category: schema.tasks.category,
      setting: schema.tasks.setting,
      iconKey: schema.tasks.iconKey,
      instructions: schema.tasks.instructions,
    }).from(schema.tasks)
      .where(filters.length ? and(...filters) : undefined)
      .orderBy(asc(schema.tasks.id))
      .limit(limit + 1);
    const hasMore = rows.length > limit;
    const items = hasMore ? rows.slice(0, limit) : rows;
    const nextCursor = hasMore ? (items[items.length - 1]!.id as string) : null;
    return { items, nextCursor };
  });
}
```

```typescript
import type { FastifyInstance } from 'fastify';
import type { ZodTypeProvider } from 'fastify-type-provider-zod';
import { eq } from 'drizzle-orm';
import { z } from 'zod';
import { db, schema } from '../../db/index.js';
import { TaskSchema } from '@humyn/shared-types';
import { buildProblemDetail, PROBLEM_SLUGS } from '../../lib/problem-detail.js';

const Params = z.object({ id: z.string().length(26) });
const PROBLEM_CT = 'application/problem+json';

export default async function tasksGetRoute(app: FastifyInstance) {
  app.withTypeProvider<ZodTypeProvider>().get('/tasks/:id', {
    schema: { params: Params, response: { 200: TaskSchema } },
  }, async (req, reply) => {
    const rows = await db.select().from(schema.tasks).where(eq(schema.tasks.id, req.params.id)).limit(1);
    if (rows.length === 0) {
      const pd = buildProblemDetail({
        slug: PROBLEM_SLUGS.notFound, title: 'Task not found',
        status: 404, detail: `id=${req.params.id}`, instance: req.id as string,
      });
      return reply.status(404).type(PROBLEM_CT).send(pd);
    }
    const r = rows[0]!;
    return {
      id: r.id, slug: r.slug, name: r.name, description: r.description,
      category: r.category, setting: r.setting, iconKey: r.iconKey, instructions: r.instructions,
    };
  });
}
```

```typescript
import type { FastifyInstance } from 'fastify';
import type { ZodTypeProvider } from 'fastify-type-provider-zod';
import { sql } from 'drizzle-orm';
import { db } from '../../db/index.js';
import { embed } from '../../lib/embedder.js';
import { TasksSearchQuerySchema, TasksSearchResponseSchema } from '@humyn/shared-types';

export default async function tasksSearchRoute(app: FastifyInstance) {
  app.withTypeProvider<ZodTypeProvider>().get('/tasks/search', {
    schema: { querystring: TasksSearchQuerySchema, response: { 200: TasksSearchResponseSchema } },
  }, async (req) => {
    const { q, category, setting, limit } = req.query;
    const queryEmbedding = await embed(q);
    // Embedding literal — built from numerics only; no injection vector
    const embeddingLiteral = `[${queryEmbedding.join(',')}]`;
    const k = 60; // RRF constant — locked at 60 per CONTEXT (Locked from upstream)
    const result = await db.execute<{
      id: string; slug: string; name: string; description: string;
      category: string; setting: string; icon_key: string; instructions: string[];
      rrf_score: number;
    }>(sql`
      WITH
        vector_ranks AS (
          SELECT
            id,
            ROW_NUMBER() OVER (ORDER BY embedding <=> ${embeddingLiteral}::vector(384)) AS rnk
          FROM tasks
          WHERE
            (${category ?? null}::text IS NULL OR category = ${category ?? null}::text)
            AND (${setting ?? null}::text IS NULL OR setting::text = ${setting ?? null}::text OR setting::text = 'either')
          ORDER BY embedding <=> ${embeddingLiteral}::vector(384)
          LIMIT 200
        ),
        lexical_ranks AS (
          SELECT
            id,
            ROW_NUMBER() OVER (
              ORDER BY ts_rank(name_search, plainto_tsquery('english', ${q})) DESC
            ) AS rnk
          FROM tasks
          WHERE
            name_search @@ plainto_tsquery('english', ${q})
            AND (${category ?? null}::text IS NULL OR category = ${category ?? null}::text)
            AND (${setting ?? null}::text IS NULL OR setting::text = ${setting ?? null}::text OR setting::text = 'either')
          ORDER BY ts_rank(name_search, plainto_tsquery('english', ${q})) DESC
          LIMIT 200
        ),
        fused AS (
          SELECT
            COALESCE(v.id, l.id) AS id,
            (
              COALESCE(1.0 / (${k}::numeric + v.rnk), 0)
              +
              COALESCE(1.0 / (${k}::numeric + l.rnk), 0)
            ) AS rrf_score
          FROM vector_ranks v
          FULL OUTER JOIN lexical_ranks l ON v.id = l.id
        )
      SELECT
        t.id, t.slug, t.name, t.description, t.category, t.setting::text AS setting,
        t.icon_key, t.instructions, f.rrf_score
      FROM fused f
      JOIN tasks t ON t.id = f.id
      ORDER BY f.rrf_score DESC
      LIMIT ${limit};
    `);
    // Drizzle's execute returns { rows: [...] } shape on node-postgres
    const rows = (result as unknown as { rows: Array<{ id: string; slug: string; name: string; description: string; category: string; setting: string; icon_key: string; instructions: string[]; rrf_score: number }> }).rows;
    return {
      items: rows.map((r) => ({
        id: r.id, slug: r.slug, name: r.name, description: r.description,
        category: r.category, setting: r.setting as 'indoor' | 'outdoor' | 'either',
        iconKey: r.icon_key, instructions: r.instructions,
        rrf_score: Number(r.rrf_score),
      })),
    };
  });
}
```

```typescript
import type { FastifyInstance } from 'fastify';
import type { ZodTypeProvider } from 'fastify-type-provider-zod';
import { ulid } from 'ulid';
import { db, schema } from '../../db/index.js';
import { TaskRequestCreateSchema, TaskRequestSchema } from '@humyn/shared-types';

export default async function taskRequestRoutes(app: FastifyInstance) {
  app.withTypeProvider<ZodTypeProvider>().post('/task-requests', {
    schema: { body: TaskRequestCreateSchema, response: { 201: TaskRequestSchema } },
    preHandler: [app.requireAuth],
    config: {
      rateLimit: {
        max: 10, timeWindow: '1 minute',
        keyGenerator: (req) => `user:${(req.user as { sub: string }).sub}`,
      },
    },
  }, async (req, reply) => {
    const userId = (req.user as { sub: string }).sub;
    const id = ulid();
    const inserted = await db.insert(schema.taskRequests).values({
      id, userId,
      name: req.body.name, description: req.body.description,
      category: req.body.category, setting: req.body.setting,
      sampleVideoS3Key: req.body.sampleVideoS3Key ?? null,
    }).returning();
    const row = inserted[0]!;
    return reply.status(201).send({
      id: row.id, userId: row.userId, name: row.name, description: row.description,
      category: row.category, setting: row.setting,
      sampleVideoS3Key: row.sampleVideoS3Key ?? undefined,
      status: row.status, createdAt: row.createdAt.toISOString(),
    });
  });
}
```

```typescript
// Parses task-taxonomy.md → 65 task rows. The markdown structure is:
//
// ## Category Name
//
// ### task-slug
// - Name: Human-readable name
// - Description: Detailed description
// - Setting: indoor | outdoor | either
// - Instructions:
//   1. Step one
//   2. Step two
//   3. Step three
//
// We parse line-by-line; sections are delimited by `## ` (category) and `### ` (task).
// The exact format may evolve; the parser fails fast on malformed entries with a
// useful error message rather than silently dropping rows.

import { readFile } from 'node:fs/promises';

export interface ParsedTask {
  slug: string;
  name: string;
  description: string;
  category: string;
  setting: 'indoor' | 'outdoor' | 'either';
  instructions: string[];
}

export async function parseTaxonomy(path: string): Promise<ParsedTask[]> {
  const text = await readFile(path, 'utf8');
  const lines = text.split('\n');
  const tasks: ParsedTask[] = [];
  let currentCategory = '';
  let currentTask: Partial<ParsedTask> | null = null;
  let inInstructions = false;
  for (let i = 0; i < lines.length; i++) {
    const line = lines[i]!;
    const catMatch = line.match(/^##\s+(.+?)\s*$/);
    if (catMatch && !line.startsWith('### ')) {
      if (currentTask?.slug) {
        tasks.push(finalizeTask(currentTask, currentCategory));
        currentTask = null;
      }
      currentCategory = catMatch[1]!;
      inInstructions = false;
      continue;
    }
    const taskMatch = line.match(/^###\s+(.+?)\s*$/);
    if (taskMatch) {
      if (currentTask?.slug) tasks.push(finalizeTask(currentTask, currentCategory));
      currentTask = { slug: taskMatch[1]!.trim(), instructions: [] };
      inInstructions = false;
      continue;
    }
    if (!currentTask) continue;
    const nameMatch = line.match(/^-\s+Name:\s*(.+?)\s*$/i);
    if (nameMatch) { currentTask.name = nameMatch[1]!; inInstructions = false; continue; }
    const descMatch = line.match(/^-\s+Description:\s*(.+?)\s*$/i);
    if (descMatch) { currentTask.description = descMatch[1]!; inInstructions = false; continue; }
    const setMatch = line.match(/^-\s+Setting:\s*(indoor|outdoor|either)\s*$/i);
    if (setMatch) { currentTask.setting = setMatch[1]!.toLowerCase() as ParsedTask['setting']; inInstructions = false; continue; }
    if (line.match(/^-\s+Instructions:\s*$/i)) { inInstructions = true; continue; }
    if (inInstructions) {
      const instMatch = line.match(/^\s*\d+\.\s+(.+?)\s*$/);
      if (instMatch) currentTask.instructions!.push(instMatch[1]!);
    }
  }
  if (currentTask?.slug) tasks.push(finalizeTask(currentTask, currentCategory));
  return tasks;
}

function finalizeTask(t: Partial<ParsedTask>, category: string): ParsedTask {
  if (!t.slug || !t.name || !t.description || !t.setting) {
    throw new Error(`task ${t.slug} is missing required fields (name/description/setting). Got: ${JSON.stringify(t)}`);
  }
  if (!t.instructions || t.instructions.length === 0) {
    throw new Error(`task ${t.slug} has no instructions`);
  }
  if (t.instructions.length > 3) {
    throw new Error(`task ${t.slug} has ${t.instructions.length} instructions; max is 3`);
  }
  return {
    slug: t.slug, name: t.name, description: t.description,
    category, setting: t.setting, instructions: t.instructions,
  };
}
```

```typescript
// Idempotent task seed — runs via `pnpm seed:tasks`.
// Re-running produces no DB changes if taxonomy + mapping are unchanged
// (ON CONFLICT (slug) DO UPDATE compares column-by-column on the application
// side and skips updates when row matches; we always upsert and let Postgres
// apply the change — the embedding is recomputed each run, which is desirable).

import { readFile } from 'node:fs/promises';
import { resolve } from 'node:path';
import { ulid } from 'ulid';
import { sql } from 'drizzle-orm';
import { db, schema } from '../src/db/index.js';
import { embed, buildEmbeddedText } from '../src/lib/embedder.js';
import { parseTaxonomy } from './parse-taxonomy.js';

const TAXONOMY_PATH = resolve(process.cwd(), '../../task-taxonomy.md');
const ICON_MAPPING_PATH = resolve(process.cwd(), '../../design-system/task-icons/mapping.json');

async function loadIconMapping(): Promise<Record<string, string>> {
  const raw = await readFile(ICON_MAPPING_PATH, 'utf8');
  return JSON.parse(raw) as Record<string, string>;
}

async function main() {
  if (!process.env.DATABASE_URL) {
    console.error('DATABASE_URL not set');
    process.exit(1);
  }
  const tasks = await parseTaxonomy(TAXONOMY_PATH);
  const iconMap = await loadIconMapping();

  console.log(`[seed-tasks] parsed ${tasks.length} tasks`);

  for (const task of tasks) {
    const iconKey = iconMap[task.slug];
    if (!iconKey) {
      throw new Error(`task ${task.slug} has no entry in mapping.json`);
    }
    const text = buildEmbeddedText({ name: task.name, description: task.description, category: task.category });
    const embedding = await embed(text);
    // Insert or update — keyed by unique slug
    await db.execute(sql`
      INSERT INTO tasks (id, slug, name, description, category, setting, icon_key, instructions, embedding)
      VALUES (
        ${ulid()}, ${task.slug}, ${task.name}, ${task.description},
        ${task.category}, ${task.setting}::task_setting, ${iconKey},
        ${JSON.stringify(task.instructions)}::jsonb,
        ${`[${embedding.join(',')}]`}::vector(384)
      )
      ON CONFLICT (slug) DO UPDATE SET
        name = EXCLUDED.name,
        description = EXCLUDED.description,
        category = EXCLUDED.category,
        setting = EXCLUDED.setting,
        icon_key = EXCLUDED.icon_key,
        instructions = EXCLUDED.instructions,
        embedding = EXCLUDED.embedding,
        updated_at = now()
    `);
    console.log(`[seed-tasks] upserted ${task.slug}`);
  }
  console.log(`[seed-tasks] done — ${tasks.length} tasks`);
}

main().catch((err) => {
  console.error('[seed-tasks] failed', err);
  process.exit(1);
});
```

| Boundary | Description |
|----------|-------------|
| client query string → SQL | `q`, `category`, `setting`, `cursor`, `limit` are user-supplied; must be parameterized |
| seed input file → DB | `task-taxonomy.md` + `mapping.json` are repo-controlled artifacts; trusted at seed time |
| embedding numeric literal → SQL | The 384-float embedding is interpolated as a string `[0.1,0.2,...]`; numerics-only so safe but worth flagging |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-1.6-01 | Tampering | SQL injection via `category`, `setting`, `q`, `cursor` query params | high | mitigate | Drizzle `sql` template parameterizes `${category}`, `${setting}`, `${q}` as bound params (Task 1). | T-1.6-02 | Tampering | Numeric injection via embedding literal | low | mitigate | Embedding is built from a `Float32Array` whose values come from the embed() output; `.join(',')` produces a numerics-only string. No user-supplied data flows into the literal. Acceptable. |
| T-1.6-03 | Denial of service | Unbounded `limit` parameter exhausts DB | medium | mitigate | Zod schema enforces `limit ≤ 100` for /tasks list, `limit ≤ 50` for /tasks/search. Rate limit (anonymous tier 30 req/min/IP from plan 04) caps request rate. |
