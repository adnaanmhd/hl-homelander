  data: number[];
  driverData: string;
  config: { dimensions: number };

  dataType(config) {
    return `vector(${config?.dimensions ?? 384})`;

Approach:
1. Run `cd apps/api && pnpm drizzle-kit generate` to emit Drizzle's auto-generated DDL into `src/db/migrations/`. Drizzle will produce a numbered SQL file with `CREATE TABLE` statements for every table in schema.ts. Inspect the output filename (drizzle-kit names them `0000_*.sql` by default).
2. Rename the generated file to `0001_init.sql` (overwriting Drizzle's auto-name) so the migrations directory is deterministic.
3. Prepend the pgvector extension creation. Append the generated tsvector column DDL + the HNSW + GIN indexes. The HNSW + generated column cannot be expressed in Drizzle 0.45's DSL — they MUST be hand-written.
