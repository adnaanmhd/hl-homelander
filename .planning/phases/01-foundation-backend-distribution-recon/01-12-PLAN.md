<objective>
Stitch together a vitest end-to-end test suite that exercises every Phase 1 endpoint in sequence (golden path) plus 9 explicit negative-path tests covering auth rejection branches, idempotency edge cases, rate-limit firing, and the consent-text boot guard. Bundle a GitHub Actions workflow so the suite runs on every PR with Node 22 + Postgres 17 + LocalStack 4.x.

Purpose: Plans 04-11 each had vitest tests scoped to their own routes. This plan is the integration-shaped sieve — it catches inter-plan regressions (e.g., plan 06's RRF query breaks because plan 02's HNSW index parameter changed; plan 07's CompleteMultipartUpload fails because plan 10 changed the bucket policy). The CI workflow makes the suite the default gate on every PR.

Output: 5 e2e test files; helper modules for fixture seeding + mocked Play Integrity verdicts; vitest.e2e.config.ts (separate from the unit-test config); a GitHub Actions workflow matrix that brings up Postgres + LocalStack as service containers, runs migrations + seed, then runs the test suite. Plan-12 is the final wave-3 plan in Phase 1 — when it passes, Phase 1 is shippable.
</objective>

- DB isolation: each test truncates the affected tables in `beforeEach` (single shared DB; pattern matches plan 05/07/08's existing tests). Per-test transactions would be cleaner but Fastify's `inject()` opens its own DB connections, breaking single-tx isolation.

- @aws-only subset: Phase 7 will expand this; plan 12 lays the structure (`describe.skipIf(!process.env.AWS_REAL)`) so Phase 7 just adds tests there.

import type { FastifyInstance } from 'fastify';
import { db, schema } from '../../src/db/index.js';
import { eq } from 'drizzle-orm';
import { S3Client, CreateMultipartUploadCommand, UploadPartCommand } from '@aws-sdk/client-s3';
import FormData from 'form-data';
import { truncateTestTables } from './helpers/seed-fixtures.js';
import { setupAuthMocks, happyPlayStorePayload } from './helpers/mock-play-integrity.js';

setupAuthMocks();
import { buildApp } from '../../src/app.js';
import { decodeIntegrityToken } from '../../src/auth/verify-play-integrity.js';

let app: FastifyInstance;
let s3: S3Client;
const BUCKET = process.env.RECORDINGS_BUCKET!;

beforeAll(async () => {
  app = await buildApp();
  s3 = new S3Client({ region: process.env.AWS_REGION!, endpoint: process.env.AWS_ENDPOINT_URL, forcePathStyle: true });

afterAll(async () => { await app.close(); });
beforeEach(async () => { await truncateTestTables(); });

describe('Golden path — full Phase 1 surface', () => {
  it('mint nonce → /auth/google → /tasks/search → /recordings init+upload+finalize → /contributions → /events → /feedback → /app/version → /recordings list+get(playback)', async () => {
    // 1. Nonce
    const nonceRes = await app.inject({ method: 'POST', url: '/auth/nonce' });
    expect(nonceRes.statusCode).toBe(200);
    const { nonceId, nonce } = nonceRes.json();

    expect(items[0].slug).toBe('make-tea');
    const taskId = items[0].id;

    // 4. /recordings/init + multipart upload + /finalize
