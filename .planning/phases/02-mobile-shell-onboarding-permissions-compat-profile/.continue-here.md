to pivot.

Operator + agent split (when proceeding):

1. **Agent prep** (~5 min):
   - Bump apkRollout `defaultConfig.versionCode` from 1 → 2 in
     `apps/mobile/android/app/build.gradle.kts`. Confirm Phase 1 plan 01-09
     locked applicationIds — only the apkRollout flavor is bumped.
   - `cd apps/mobile/android && ./gradlew :app:assembleApkRolloutDebug`.
   - `sha256sum apps/mobile/android/app/build/outputs/apk/apkRollout/debug/app-apkRollout-debug.apk` — capture the hash.
   - `cd apps/mobile/android/app/build/outputs/apk/apkRollout/debug && python3 -m http.server 9000 &` — host the new APK.
   - Identify the LAN-reachable URL: `ipconfig getifaddr en0` (or `ifconfig`)
     for the Mac's LAN IP, then `http://<LAN-IP>:9000/app-apkRollout-debug.apk`.
   - Craft the SQL UPDATE for `app_versions` table:
     ```sql
     UPDATE app_versions
     SET min_supported='99.0.0',
         apk_url='http://<LAN-IP>:9000/app-apkRollout-debug.apk',
         apk_sha256='<sha-from-step-3>'
     WHERE flavor='apkRollout';
     ```
     Run via `psql "$DATABASE_URL" -c "..."`.
2. **Operator on-device** (~10–15 min):
   - Cold-start app on Pixel 10a (the device may need to relaunch after the
     pm clear from this pause).
   - Splash → ForceUpgradeScreen renders 'Update to continue.'
   - Tap Update → APK download → on hash-match: 'Allow from this source'
     prompt may appear → grant → PackageInstaller dialog → tap Install.
   - App updates and re-launches with versionCode=2.
   - `adb shell dumpsys package ai.humynlabs.capture.apk | grep versionCode`
     → confirm `versionCode=2`.
3. **Hash-mismatch test** (~5 min):
   - Update backend `apk_sha256` to all zeros (or an obviously wrong value).
   - Force-stop + cold-start the previous-versionCode build (you may need
     to install versionCode=1 again first via `adb install -r`).
   - Tap Update → after download, JS-side rejects → 'Update failed
     (integrity check). Try again or contact support.' Alert renders.
   - `adb logcat | grep -E "force_upgrade_apk_hash_mismatch|hash-mismatch|integrity check"`
     → `force_upgrade_apk_hash_mismatch` Analytics event fires (Pattern 50:
     structural gate guarantees `launchInstaller` is NEVER called after
     hash-mismatch — T-2.20-01 mitigation).
4. **Cleanup**:
   - Reset backend `min_supported` and `apk_sha256` to real values.
   - Stop the python http server (`fg` then Ctrl-C, or `kill %1`).
   - Revert apkRollout versionCode bump in build.gradle.kts (it'll be
     committed back to 1 later in the smoke-walk-complete commit).
